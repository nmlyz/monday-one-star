A tiny program that writes a one-star review of Monday, written as if Monday were a restaurant, to a file. The line is 21 words and 113 characters: the bill arrives before the food, five days plus tax, and the waiter is already asking about Tuesday.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Standard library only, no network, deterministic: two runs produce byte-identical output.

## The line

> One star. The bill came before the food: five days, plus tax, and the waiter already wants to know about Tuesday.

Thirty-six candidate lines were written from deliberately different angles, the cliches were thrown out, and the survivors were judged pairwise against the brief by three readers — a weary office worker weighing which line it would drop in the group chat, a foodie weighing whether it reads like a real diner's complaint, and a group-chat friend weighing which line is sharpest to forward. The bill-before-food line won the final 2-1.
